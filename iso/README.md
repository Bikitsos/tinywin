# Source Windows 11 ISO Folder

Place your official Windows 11 `.iso` file in this folder (or directly in the project root `C:\Users\Bikitsos\projects\tinywin\`).

`Build-TinyWin11.ps1` will automatically detect it and build the customized ISO to:
`C:\Users\Bikitsos\projects\tinywin\output\POS_READY_2026.iso`
